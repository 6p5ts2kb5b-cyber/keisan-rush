# まなびラッシュ（旧：けいさんラッシュ）

小学1年生〜中学3年生の「さんすう・数学」「えいご」「かんじ」を、ブラウザで遊びながら復習できるRPGです。

## あそびかた
- タイトルでセーブファイル（5つ）を選び、名前を入れてスタート
- 6つの島のマップから単元（全49単元）を選んでバトル
- コマンドを選び、計算に正解すると技が決まる
  - 速く解くとクリティカル
  - 正解を続けるとひっさつゲージがたまる
  - 6つの属性の相性あり
- 倒した昆虫をつかまえて図鑑に登録（世界の昆虫100種＋SP）
- つかまえた昆虫や昆虫の戦士でパーティを組める
- 🔢 さんすう ／ 🔤 えいご ／ 📝 こくご ／ 🔀 まぜる：島のステージ画面で、バトルに出る教科を切りかえられる
  - えいご：小1〜小6はレベル別（聞いて絵を選ぶ・絵を見て単語・アルファベット・数・あいさつ・会話・つづり・意味）。🔊 ボタンで何度でも英語を聞ける（端末の読み上げ機能を使用）
  - 答えたあとに「えいご ポイント」で意味や文法のポイントが出る
- 練習用の「こんちゅうガチャ」（問題に正解すると昆虫ゲット、💎は使わない）
- 島マップの「🌐 せかい」から、ほかのモードへ
  - 📐 算数テストの島：11級（小1）〜3級（中3）。級ごとに「けいさん１・２／文章題／もぎ しけん」と「ごうかく しけん」。中学数学（正負の数・方程式・連立方程式・一次関数・確率・展開・因数分解・平方根・二次方程式・三平方の定理など）も出る。正解率70%で合格証
  - 🗽 英語テストの島：えいごジュニア・5級（中1）・4級（中2）・3級（中3）。「たんご／かいわ／ぶんぽう／リスニング」と「ごうかく しけん」。並べかえ・会話・文法・リスニング問題
  - ※ 検定の島の問題は、各検定の出題範囲を参考にした オリジナル問題です（公式の過去問ではありません）
  - 🖌 漢字テストの島：10級（小1）〜6級（小5）。「よみ／かき／かくすう・ひつじゅん（部首）／もぎ しけん」と「ごうかく しけん」。2020年度からの学年別漢字配当表（小1〜小5の835字）に対応。かきは 同じ読みの字・形のにた字から選ぶ。送りがな・部首・筆順（赤い画は何画目？）も出る
  - ✍ なぞり書き：835字の書きじゅんを指でなぞる練習。書きはじめと向きが合っているかを判定し、まちがえると お手本が出る。「おてほん なし」で見ないで書く練習も
  - 👖 古着 西海岸編：Levi's の歴史（1853年・1873年のリベット特許・XX・ツーホース・赤タブ）、501XX（1947／1955）・大戦モデル・隠しリベット・オフセット・ギャラ入り／なし・片面／両面タブ、BIG E・66前期／後期・赤耳・80s・90s USA製（ボタン裏 555／524）、501／505／502／517 のシルエット、Gジャン 506XX〜70505 のディテール
  - 🧥 古着 東海岸編：Lee（H.D.リー、ユニオンオール、101・101Z・101J・ストームライダー・91-J、レイジーS、ヘアオンハイド）、Wrangler とブルーベル社（ロデオ・ベン、13MWZ、111MJ・11MJZ・24MJZ、7つのアイコン）、三大ストアブランド（シアーズ・JCペニー・モンゴメリーワード）
  - 🗾 古着 日本編：ベルベルジン（原宿）・Mr.Clean（富ヶ谷）・オワッテルマン・古着屋パンダ・ネイジャパ（公開記事やチャンネル説明で確認できた事実のみ）と、極東リーバイス（香港・フィリピン・マカオ製、ボタン裏347）・日本製復刻（502XX・702XX・J22）
  - パッチ・タブ・ボタン裏刻印・赤耳・ステッチなどの「拡大図」を見て答える問題つき（写真ではなくオリジナルの図解）
  - 古着クイズの答えは公式資料とビンテージショップの資料を照らし合わせたもの。資料によって年がずれる項目は「年代」やディテールで出題。ステージをクリアすると「古着カード」（図解つき）が集まる
  - 🗾 にっぽん旅：47都道府県の市や町をめぐるスタンプラリー（名産・昆虫クイズ）
  - 🌊 海編・🦌 陸編・🕊 空編：日本の8地方の生き物をつかまえる
  - 🌏 アジア編・🏰 ヨーロッパ編：国と都市をめぐって昆虫と陸の生き物をつかまえる
  - 🌺 沖縄編：沖縄本島 → 宮古島 → 石垣島 → 竹富島 → 与那国島を船でわたる（31ステージ・39種）。うちなーぐち・れきし・沖縄りょうり・名所のクイズが沖縄ことばで出て、答えると「まめちしき」が出る。BGMは琉球音階のオリジナル曲（三線）
  - ⚒ かじや：つかまえた生き物の「そざい」でぶきを作る（長剣・太刀・短剣・双剣・ハンマー・やり・弓矢・ボウガンの8しゅるい）
  - 🎵 楽器編：楽器クイズに20問正解で楽器ゲット。BGMにしたり、まほうつかいに持たせてバトルで演奏できる
  - 🔁 こうかん：コードで生き物をともだちと交換
- 食べものを昆虫にあげると進化、昆虫に職業（せんし・まほうつかい・そうりょ・ぶとうか・けんじゃ）をつけられる
- 戦闘不能のなかまは ⛪ 教会で復活
- どこかに ひみつの なかまが かくれているらしい…
- そざい：生き物をつかまえると、ツノ・羽・うろこ・貝がら・キバなどがもらえる。あまったストックは図鑑の360°ビューで「そざいにする」。楽器編の正解で「おんぷのかけら」、楽器ゲットで「きらめく弦」
- ぶきの とくちょう（「こうげき」で発動）：長剣=かいしん／太刀=コンボで強化／短剣=速く正解で2回／双剣=2連撃／ハンマー=きぜつ／やり=ぼうぎょ無視／弓矢=3連撃／ボウガン=にがて属性で攻撃
- ガチャのキラキラカプセルには、レアなそざいや、ガチャでしか出ないぶきが入っていることも
- にっぽん旅では、47都道府県それぞれの「ご当地ことば（方言）」であいさつ・クイズが出る。名産・名所クイズも追加
- 📷 写真モード：写真から名産を登録（各市町村5枚・各県50枚まで）
- 世界は順番にひらく：にっぽん旅コンプリート → 海編 → 陸編 → 空編 → アジア編 → ヨーロッパ編。沖縄編もにっぽん旅コンプリートでひらく（ひらく前でも「おためしバトル」が1日1回できる）

## おうちの方へ
- バトルは1日5回まで（この端末で数えます）。こえたときは、おうちの人の パスワードを入れると、その日にあと何回バトルしてよいかと、1日の回数を設定できます。
- 設定画面の「🤫 ひみつキャラ（お子さんモデル）」で、お子さんの名前・好きな虫・好きな色を登録できます。その名前でファイルを作ると、お子さんがモデルの「ゆうしゃ」がなかまになります。
- タイトル画面の「👪 おうちの方へ」からも設定できます。「せかいを ぜんぶ ひらく」をオンにすると、コンプリート前でもすべての世界に行けます。

## 音楽について
BGM・楽器の曲は、著作権の切れた曲（作者不明の民謡や昔の作曲家の曲）か、このゲームのためのオリジナル曲だけです。沖縄編の曲は琉球音階（ド・ミ・ファ・ソ・シ）で作ったオリジナル曲で、市販の曲は入っていません。

## うごかしかた
`index.html` をブラウザで開くだけで遊べます（1ファイル・外部ライブラリなし）。
GitHub Pages を有効にすると、URLから遊べます。

セーブデータはブラウザの localStorage に、写真は IndexedDB に保存されます（端末・ブラウザごと）。
写真からの自動よみとりは Claude のアプリで開いたときだけ使えます。

## 🌐 English version
- タイトル画面の「🌐 English」ボタンで 英語版に きりかわる（もどすときは「🌐 日本語に する」）。セーブデータは そのまま。

- English：英語を 話す 子ども向けに、絵を見て 単語・聞いて 絵を えらぶ・つづり・ぬけた 文字・はじめの 文字・数・あいさつの 返事。
- Kanji：「日本の 漢字を 学ぼう」— 漢字の 意味（英語）を えらぶ・意味から 漢字を えらぶ・画数・書き順。なぞり書きも 意味つき。
- 日本人向けの 英語（英語テストの島・中学英語の島）と 古着編は 英語版では 出ない。
